使用说明

  • 网页工具：直接双击对应 .html 文件即可在浏览器中离线使用，无需联网、无需安装。
  • Python 工具：进入 python工具 下对应课时文件夹，运行 python 工具名.py（需要 Python 3，自带 Tkinter 即可；个别工具的 matplotlib / pandas 为可选增强，未安装会自动降级）。每个文件夹内附“使用说明.txt”和示例数据。
  • 安全边界：全部使用虚拟传感器、虚拟执行器与虚构的设备 ID / Topic；不扫描真实网络、不控制真实设备；本地服务只绑定 127.0.0.1。
  • 学习数据只保存在本机浏览器（localStorage）中，每个页面底部都提供“清除本机学习数据”按钮，成果可导出为 .txt / .json 留存。
  • 建议教学顺序：第1单元按节推进并贯通“智能农植园”项目；第2单元围绕“在线数字气象站”完成采集、整理、分析与可视化，最后汇总项目报告。
