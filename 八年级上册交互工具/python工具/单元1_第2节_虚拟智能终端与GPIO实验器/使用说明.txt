虚拟智能终端与GPIO实验器 · 使用说明
（第1单元 第2节《物联网的终端设备》配套 Python 工具）
============================================================

一、运行方法
1. 需要 Python 3.8 及以上（自带 tkinter，无须任何第三方库）。
2. 在本文件夹打开终端 / 命令行，执行：
   python3 虚拟智能终端与GPIO实验器.py
   （Windows 下可执行：python 虚拟智能终端与GPIO实验器.py）

二、界面分区
· 左上「指令区」：13 个常用指令按钮，点击即执行；
· 左中「手动输入指令」：自己敲指令，回车或点「▶ 执行」；
· 左下「引脚模式配置表」：实时显示 P0~P16 的模式与当前值；
· 右上「虚拟开发板」：OLED 显示区、按钮 A/B（可用鼠标按住模拟按下）、
  LED×2、蜂鸣器图标、引脚条（颜色表示模式）；
· 右下「操作日志」：每条指令的执行结果，带时间戳；
· 底部状态栏：绿色=成功，红色=出错（含原因和改法）。

三、支持的指令（详见程序内「帮助 / 指令手册」）
  oled.show("你好，物联网")   OLED 显示文字（≤24 字符）
  oled.clear()                清空屏幕
  led.on(1) / led.off(1)      点亮 / 熄灭 LED1（LED2 同理）
  buzzer.beep()               蜂鸣器响一声（Windows 用 winsound 发声，
                              其他系统自动降级为图标闪烁 + 状态提示）
  pin.mode("P5","IN")         设置引脚模式：IN / OUT / ANALOG / PWM
                              （ANALOG 仅 P0/P1/P2 支持）
  pin.write("P8",1)           向输出引脚写值（OUT 写 0/1，PWM 写 0~1023）
  pin.read("P5")              读输入引脚（IN 返回 0/1，ANALOG 返回 0~4095）

四、建议实验流程（对应教材实验活动）
1. 数字输入实验（教材表 1.2.5）：
   ① 执行 pin.mode("P5","IN")；
   ② 执行 pin.read("P5")，记下读数（应为 1）；
   ③ 用鼠标按住开发板上的按钮 A，同时再执行一次 pin.read("P5")，
      记下读数（应为 0）；
   ④ 填写：按下=0，放开=1。
2. 输出实验：pin.mode("P8","OUT") → pin.write("P8",1)；再故意把 P8 设成
   IN 后写入，观察诊断信息，理解“输入引脚不能写”。
3. 点击「导入指令脚本」选择本文件夹的 示例指令脚本.txt，观看自动演示。
4. 实验完成后用「导出记录CSV / JSON」保存实验记录。

五、常见问题排查
1. 提示 “No module named tkinter”：Linux 下执行 sudo apt install python3-tk。
2. buzzer.beep() 没有声音：非 Windows 系统没有 winsound，属正常降级，
   以蜂鸣器图标闪烁和状态栏提示代替。
3. pin.read / pin.write 报错“还未设置模式”：这是刻意设计——和真实
   开发板一样，必须先 pin.mode() 设置模式再读写。
4. 导出的 CSV 乱码：已用 utf-8-sig 编码，请用 WPS/Excel 正常打开。

六、安全说明
本工具完全离线，全部硬件均为画布模拟，不扫描网络、不连接和控制
任何真实设备，不保存任何真实密钥。
