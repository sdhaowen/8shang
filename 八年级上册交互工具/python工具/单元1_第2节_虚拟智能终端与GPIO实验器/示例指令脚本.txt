# 示例指令脚本 · 虚拟智能终端与GPIO实验器
# 用法：在工具中点「导入指令脚本」选择本文件，指令将每 0.7 秒自动执行一条。
# 以 # 开头的行是注释，不会被执行。

# —— 第一幕：点亮 OLED（对应教材“在屏幕上输出信息”体验活动）——
oled.show("智能农植园系统")
buzzer.beep()

# —— 第二幕：配置引脚模式（先设模式，再读写）——
pin.mode("P5","IN")
pin.mode("P8","OUT")
pin.mode("P0","ANALOG")

# —— 第三幕：数字输出，控制执行器 ——
pin.write("P8",1)
led.on(1)
led.on(2)
led.off(2)

# —— 第四幕：读取输入 ——
pin.read("P5")
pin.read("P0")

# —— 第五幕：故意犯错，观察诊断信息 ——
pin.write("P5",1)
pin.mode("P8","ANALOG")

# —— 收尾 ——
oled.show("实验完成！")
buzzer.beep()
