====================================================
本地智能农植园实验平台 · 使用说明
配套课时：清华版《信息科技》八年级上册 第1单元 第6节《物联网系统的搭建》
====================================================

一、运行方法
  1. 安装 Python 3.8 及以上版本（自带 Tkinter 与 sqlite3，无需第三方库）。
  2. 在本文件夹打开终端/命令行，执行：
       python3 本地智能农植园实验平台.py
     Windows 系统可执行：
       python 本地智能农植园实验平台.py
  3. 程序会在同目录自动创建数据库文件 农植园数据.db。

二、七大功能说明
  ① 监控与控制（第1页）
     · 4 个虚拟传感器滑块：温度(-10~60℃)、空气湿度(0~100%)、
       光照(0~2000lx)、土壤湿度(0~100%)；
     · 勾选"自动随机变化"让数据自动波动，更像真实环境；
     · 采样间隔 1~10 秒可调；实时数值与"合理范围检查"提示；
     · 三条阈值规则（水泵/风扇/补光灯）阈值可改，蜂鸣器在数据
       超合理范围时自动报警；
     · 自动/手动模式切换；Canvas 实时绘制执行器状态动画。
  ② 消息中转（第2页）
     · 点"启动消息服务"开启进程内教学 Broker（queue+threading 实现）；
     · 每次采样，传感终端把 4 条数据发布到各自 Topic
       （如 smartfarm/device01/temperature），自动控制端订阅接收；
     · 日志表显示 时间/发布者/Topic/消息/订阅者；
     · 试验：停止消息服务后，消息会显示"✗ 服务器未启动，消息丢失"，
       这正是真实系统中"MQTT 服务器未启动"故障的表现。
     · 与真实 MQTT 的对应：publish/subscribe 概念与教材 siot 库一致，
       只是不走网络（真实 MQTT 默认走 1883 端口）。
  ③ 数据记录（第3页）
     · 每次采样写入 SQLite；Treeview 查看最近 20/50/100/200 条；
     · 可按时间关键词筛选（如输入 14: 查看 14 点的数据）；
     · 可导出 CSV（utf-8-sig，Excel 可直接打开）；
     · "清空示例数据"有确认对话框，防止误删。
  ④ 实时曲线（第4页）
     · Canvas 自绘最近 120 次采样的 4 条曲线：
       红=温度、蓝=空气湿度、橙=光照、绿=土壤湿度；带网格与图例。
  ⑤ 系统诊断（第5页）
     · 一键检查：消息服务是否启动 / 发布与订阅 Topic 是否匹配 /
       数据是否超合理范围 / 控制规则是否冲突 / 数据文件是否可写；
     · 每项给出 ✔/✖ 和修复建议。
  ⑥ 项目导出（第6页）
     · 填写项目小结，导出包含设备配置、Topic 清单、控制规则、
       数据摘要、测试日志的 JSON 或 TXT 项目报告。

三、常见问题排查
  Q1：提示 No module named 'tkinter'？
      Linux 请安装：sudo apt install python3-tk
  Q2：曲线不动 / 数据不变？
      勾选"自动随机变化"，或手动拖动传感器滑块。
  Q3：执行器不响应？
      确认在自动模式；确认已启动消息服务（自动控制以"订阅收到的数据"
      为准，服务停止就收不到新数据——这是有意的教学设计）。
  Q4：想重新开始？
      在数据记录页清空数据；关闭程序后删除 农植园数据.db 也可。
  Q5：程序关不掉？
      正常点窗口右上角 ×，程序会自动停止线程并关闭数据库。

四、安全说明
  本平台完全离线：消息中转在进程内模拟，不绑定网络端口、
  不扫描网络、不连接真实设备、不保存任何真实账号密钥。
