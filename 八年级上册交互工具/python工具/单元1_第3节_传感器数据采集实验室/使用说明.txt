====================================================
传感器数据采集实验室（虚拟）· 使用说明
配套课时：《信息科技》八年级上册 第1单元 第3节 物联网的感知
====================================================

一、运行方法
1. 确认电脑安装了 Python 3.8 及以上版本（自带 tkinter，无需安装任何第三方库）。
2. 在本文件夹中打开终端（命令行），执行：
       python3 传感器数据采集实验室.py
   Windows 下也可以执行：
       python 传感器数据采集实验室.py
   或直接双击该 .py 文件（若系统已关联 Python）。

二、功能介绍
1. 四通道虚拟传感器：温度(℃)、空气湿度(%RH)、光照(lx)、土壤湿度(%)。
   每个通道有三种数据模式：
   · 手动滑块 —— 拖动滑块决定读数，好比亲手旋转教材中的旋钮传感器；
   · 自动漂移 —— 数值缓慢随机变化，模拟自然环境的缓变；
   · 正弦波动 —— 数值周期起伏，模拟昼夜温度/光照变化。
2. 采样间隔：0.2~10 秒可调，体会"采样"概念（间隔越小，曲线越细腻）。
3. 实时曲线：右上方黑色示波器区域，多通道不同颜色，底部有图例；
   纵轴统一按各通道量程的百分比显示。
4. 阈值报警：给通道填写"下限/上限"（留空则不报警）。数值超限时：
   · 该通道读数变红；
   · 右下角"报警日志"记录一条超限信息。
   例如给"土壤湿度"设下限 40，就模拟了智能农植园的"缺水提醒"。
5. 数据表格：显示最近 200 条采样记录（最新在最上面）。
6. 导出：可将采样记录、报警日志分别导出为 CSV 文件（UTF-8 带 BOM，
   Excel/WPS 直接打开不乱码）。文件夹中附带"示例数据_传感器采样记录.csv"
   供参考格式。
7. 清空数据 / 全部重置 / 帮助按钮见顶部工具条。

三、教学建议（与教材呼应）
· 教材表1.3.3 要求记录旋钮传感器的模拟输入数值范围：可把"光照"通道
  设为手动滑块模式，拖到最左、最右，观察并记录最小值与最大值。
· 教材"智能农植园的数据采集"：为土壤湿度设下限阈值，观察缺水报警，
  理解"土壤缺水时输出值将减少"。

四、常见问题排查
1. 提示找不到 tkinter：Linux 下执行 sudo apt install python3-tk 后重试。
2. 中文显示为方块：更换系统默认中文字体即可（程序使用微软雅黑/系统字体）。
3. 曲线不动：请确认已点击【开始采集】，且未处于停止状态。
4. 导出的 CSV 打开乱码：请用支持 UTF-8 的软件打开；本工具已写入 BOM，
   Excel 通常可直接识别。
5. 本工具不连接任何真实传感器与网络，所有数据均为虚拟仿真。
