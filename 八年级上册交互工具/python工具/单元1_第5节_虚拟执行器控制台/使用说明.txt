====================================================
虚拟执行器控制台 · 使用说明
配套课时：清华版《信息科技》八年级上册 第1单元 第5节《物联网的控制》
====================================================

一、运行方法
  1. 安装 Python 3.8 及以上版本（自带 Tkinter，无需安装任何第三方库）。
  2. 在本文件夹打开终端/命令行，执行：
       python3 虚拟执行器控制台.py
     Windows 系统可执行：
       python 虚拟执行器控制台.py
     或直接双击 .py 文件（若已关联 Python）。

二、功能介绍
  1. 虚拟设备面板（中间 Canvas）：
     - LED补光灯：可用 R/G/B 三个滑块调色（对应教材 RGB 混色原理）；
     - 蜂鸣器：开启时图标闪烁并画出声波；Windows 系统可真实发声；
     - 继电器：显示高/低电平与触点吸合动画，带被控台灯；
     - 舵机：拖动"舵机角度"滑块，摇臂转到 0~180°；
     - 风扇：开启后扇叶旋转（after 驱动动画）；
     - 水泵：开启后有水滴上喷动画。
  2. 虚拟传感器（左侧）：温度 0~50℃、土壤湿度 0~100%、光照 0~1000lx。
  3. 控制规则编辑器（右侧）：
     选择 传感器 + 比较符 + 阈值 + 动作 + 执行器，点"＋添加"；
     可删除、启用/停用；规则列表用表格展示。
  4. 手动/自动模式：
     手动模式下点设备按钮直接开关；
     自动模式下由规则接管，拖动传感器滑块即可看到执行器自动响应，
     日志记录触发时间与原因。
  5. 控制序列播放：内置一段演示序列（LED→舵机→继电器→风扇→水泵→蜂鸣器），
     按时间顺序执行，可播放/暂停/重置。
  6. 导入导出：菜单"文件"可导出规则/日志为 JSON 或 CSV，
     可导入规则 JSON（本文件夹附带 示例规则.json 可直接导入体验）。

三、常见问题排查
  Q1：提示 No module named 'tkinter'？
      Linux 系统请安装：sudo apt install python3-tk
  Q2：蜂鸣器不发声？
      只有 Windows 支持 winsound 真实发声，其他系统自动降级为图标闪烁；
      也可能勾选了"蜂鸣器静音"。
  Q3：自动模式下点设备按钮没反应？
      这是有意设计：自动模式下执行器由规则控制，请切回手动模式。
  Q4：添加规则后设备不动作？
      检查：是否已切到自动模式；规则是否"启用"；比较符方向是否写反
      （如风扇应在温度 > 阈值时开启）。
  Q5：中文乱码？
      请确保终端使用 UTF-8 编码；导出的 CSV 使用 utf-8-sig，Excel 可直接打开。

四、安全说明
  本工具全部设备为虚拟模拟，不扫描网络、不连接任何真实硬件。
