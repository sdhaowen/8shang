物联网原理实验室 · 使用说明
（第1单元 第1节《从互联网到物联网》配套 Python 工具）
============================================================

一、运行方法
1. 确认已安装 Python 3.8 及以上版本（自带 tkinter，无须安装任何第三方库）。
2. 在本文件夹打开终端 / 命令行，执行：
   python3 物联网原理实验室.py
   （Windows 下可执行：python 物联网原理实验室.py，或双击该文件）

二、功能介绍
1. 虚拟传感器（设备端）：温度（-10~50℃）、湿度（0~100%）、光照（0~1000lx）。
   · 自动随机漂移模式：数值自动小幅波动，模拟真实环境变化；
   · 取消勾选后可手动拖动滑块，模拟“人为制造”环境变化。
2. 三栏数据流转：
   ① 设备端（感知）→ ② 本地平台（传输+处理）→ ③ 控制端（应用），
   每条消息带时间戳，直观展示物联网四个环节的分工。
3. 实时曲线：下方黑色画布用 tkinter.Canvas 自绘三条曲线，保留最近 120 个采样点。
4. 阈值报警：可分别设置温度/湿度/光照上限，超限时状态栏变红、控制端出现 ⚠ 告警。
5. 采样间隔：0.5~5 秒可调。
6. 导出 CSV：把全部采集记录（时间、三项读数、状态）保存为 UTF-8 CSV 文件，
   可用 WPS / Excel 打开分析。本文件夹附有 示例数据.csv 供参考。
7. 重置：清空数据、日志与曲线；帮助：查看实验步骤与教材知识对应关系。

三、建议实验流程
1. 点击「开始采集」，观察消息从设备端流到控制端的完整链路；
2. 把温度阈值改为 20，等待（或手动拖高温度滑块）触发一次超限报警；
3. 把采样间隔从 1 秒改为 5 秒，对比数据上报频率；
4. 导出 CSV，数一数报警发生了几次、发生在什么时刻。

四、常见问题排查
1. 提示 “No module named tkinter”（多见于 Linux）：
   Ubuntu/Debian 执行 sudo apt install python3-tk 后重试。
2. 窗口字体发虚或过小：属于系统缩放问题，可在系统显示设置中调整缩放比例。
3. 导出的 CSV 用 Excel 打开乱码：本工具已使用 utf-8-sig 编码，一般不会乱码；
   若仍乱码，请用 WPS 或记事本打开确认。
4. 点“开始采集”后曲线不动：请确认已勾选“自动随机漂移模式”，
   或手动拖动滑块产生变化。

五、安全说明
本工具完全离线，仅在进程内模拟“设备端-平台-控制端”，不扫描网络、
不连接和控制任何真实设备，不保存任何真实账号或密钥。
