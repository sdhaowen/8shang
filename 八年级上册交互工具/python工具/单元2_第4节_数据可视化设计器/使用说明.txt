数据可视化设计器 · 使用说明
=====================================================
课时：清华版《信息科技》八年级上册 第2单元 第4节《数据可视化》
配套项目：在线数字气象站（荔波小七孔气温探究）

一、运行方法
-----------------------------------------------------
1. 安装 Python 3.8 或更高版本（自带 tkinter，无须额外安装）。
2. 在本文件夹打开终端/命令行，执行：
       python3 数据可视化设计器.py
3. 本工具完全离线运行：
   · 未安装 matplotlib 时，自动使用 tkinter.Canvas 自绘引擎，
     四种图表（柱状/折线/饼/散点）都能绘制，坐标轴刻度齐全，
     图片可另存为 PostScript(.ps) 文件；
   · 已安装 matplotlib（pip install matplotlib）时，自动切换为
     matplotlib 引擎，图表更精细，并支持直接导出 PNG 图片。
   顶部状态文字会显示当前使用的绘图引擎。

二、功能介绍
-----------------------------------------------------
1. 数据载入
   · 「导入 CSV」：自动尝试 UTF-8、GBK 等常见编码，第一行为表头。
   · 「示例：24小时气象」：小七孔一天 24 小时气温、湿度数据。
   · 「示例：一周天气」：晴/多云/阴/小雨天数统计（适合饼图）。
2. 图表设计（左侧属性面板）
   · 选择 X 字段、Y 字段（Y 必须是数值列）；
   · 选择图表类型：柱状图（比大小）、折线图（看趋势）、
     饼图（看占比）、散点图（看两变量关系）；
   · 设置标题、X/Y 轴名称、颜色方案、是否显示图例；
   · 点「绘制图表」即时渲染，点「保存图片」导出。
3. 配置的保存与复现
   「保存配置 JSON」把当前所有设计参数存成 .json 文件；
   「载入配置 JSON」可一键恢复以前的设计。
4. 「导出实验记录」：把本次所有操作步骤与当前配置保存为 TXT。
5. 「帮助」：图表类型选择方法与常见问题。

三、建议的课堂探究
-----------------------------------------------------
· 用「24小时气象」示例绘制气温折线图，观察最高气温出现在
  14 时、最低气温出现在日出前后（呼应单元项目问题）。
· 把同一组数据分别画成柱状图和折线图，讨论哪种更适合看趋势。
· 用「一周天气」示例绘制饼图，说说晴天占比约是多少。
· 以「气温」为 X、「湿度」为 Y 画散点图，观察负相关关系。

四、常见问题排查
-----------------------------------------------------
1. 提示“Y 字段没有数值数据”：Y 必须选数值列（如「气温」）。
2. 散点图报提示：散点图要求 X 也是数值列；X 若是文字（如
   「天气」），请换成柱状图或饼图。
3. 饼图提示项目太多：饼图适合类别少的占比数据，请载入
   「一周天气」示例或改用其他图表。
4. 导入的中文 CSV 乱码：程序自动尝试多种编码；仍失败时请把
   文件另存为 UTF-8 编码。
5. matplotlib 模式下中文显示为方块：系统缺少中文字体，可安装
   黑体/微软雅黑等字体，或卸载 matplotlib 改用自绘引擎。
6. Linux 提示找不到 tkinter：执行 sudo apt install python3-tk。
