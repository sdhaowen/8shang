统计分析工作台 · 使用说明
=====================================================
课时：清华版《信息科技》八年级上册 第2单元 第3节《数据的统计分析》
配套项目：在线数字气象站（荔波小七孔气温探究）

一、运行方法
-----------------------------------------------------
1. 安装 Python 3.8 或更高版本（自带 tkinter，无须额外安装）。
2. 在本文件夹打开终端/命令行，执行：
       python3 统计分析工作台.py
   Windows 下也可以直接双击该 .py 文件（若已关联 Python）。
3. 本工具完全离线运行，仅使用 Python 标准库；
   如果电脑上装有 pandas，会自动用它加速 CSV 读取（非必需）。

二、功能介绍
-----------------------------------------------------
1. 数据载入
   · 「导入 CSV」：选择任意 CSV 文件，程序自动尝试 UTF-8、GBK 等
     常见编码，第一行视为表头。
   · 「载入内置气象示例」：一键载入小七孔气象站 24 小时示例数据
     （时刻、气温、湿度、光照、风力、时段），与本单元项目情境一致。
2. ① 描述统计
   选择一个数值字段，一键计算：计数、总和、平均值、中位数、众数、
   最大值、最小值、极差、标准差，结果显示在「统计结果」页。
3. ② 分组统计
   选择分组字段（如「时段」）和求平均字段（如「气温」），程序按组
   求平均，用表格 + 柱状图对比显示（例如白天 vs 夜间平均气温）。
4. ③ 回归分析（手写最小二乘法）
   选择自变量 X（如「时刻」）与因变量 Y（如「气温」），拟合趋势
   直线 y = b·x + a，显示斜率、截距与 RMSE 误差，并绘制散点+趋势
   线图；在预测框输入 X 值可预测对应的 Y 值。
5. 分析结论
   每次分析后程序自动追加一条结论草稿，你可以修改措辞；
   「导出报告 TXT」把实验记录、统计结果、回归方程与结论保存为
   文本报告；「导出结果 CSV」保存统计表格，可再导入电子表格软件。
6. 「帮助」按钮：查看每个统计量的含义与使用建议。

三、建议的课堂探究
-----------------------------------------------------
· 用内置数据回答项目问题：一天最高气温是否出现在 14 时？
  最低气温是否出现在日出前后？（看最大/最小值与数据表）
· 按「时段」分组对比白天与夜间平均气温，思考光照的影响。
· 以「气温」为 X、「湿度」为 Y 做回归，观察负相关关系。

四、常见问题排查
-----------------------------------------------------
1. 提示"该字段没有可用的数值数据"：
   所选列是文字（如「时段」），描述统计请选数值列。
2. 分组太多被拒绝：
   分组字段应是类别较少的列（如「时段」只有白天/夜间两类），
   不要用连续数值列（如「气温」）做分组。
3. 导入的中文 CSV 乱码：
   程序已自动尝试多种编码；若仍失败，请用记事本/WPS 将文件
   另存为 UTF-8 编码后重新导入。
4. Linux 下提示找不到 tkinter：
   执行 sudo apt install python3-tk 安装后重试。
5. 窗口图表为空白：
   请先点击对应的分析按钮；调整窗口大小后重新点击按钮即可重绘。
