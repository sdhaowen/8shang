====================================================
数据与大数据实验室 · 使用说明
配套课时：清华版《信息科技》八年级上册
第2单元 第1节《从数据到大数据》
====================================================

一、运行方法
1. 确认已安装 Python 3.8 及以上版本（自带 Tkinter，无需安装任何第三方库）。
2. 在本文件夹打开终端/命令行，执行：
       python3 数据与大数据实验室.py
   Windows 下也可以执行：
       python 数据与大数据实验室.py
   或直接双击 .py 文件（若系统已关联 Python）。

二、功能介绍（四个标签页）
【标签页1 数据集生成与类型统计】
  · 生成"模拟气象数据集"：模拟在线数字气象站连续多天、每天 24 小时
    的观测记录（气温呈"14 时前后最高、日出前后最低"的规律，
    呼应单元项目"小七孔在线数字气象站"）。
  · 生成"模拟共享单车骑行数据集"（条数可调）。
  · 右侧"数据体检卡"自动统计：记录条数、每个字段是数值型还是文本型、
    单条记录字节数、整个数据集的存储量。
  · 菜单"文件"可导入已有 CSV（自动识别 UTF-8 / GBK），
    也可把当前数据集导出为 CSV（本文件夹附示例：示例气象数据集.csv）。

【标签页2 产生速度与存储估算】
  · 速度模拟：拖动滑块设定"每秒生成条数"，点击"开始"，
    观察累计条数、内存估算、运行秒数不断增长——体验大数据"高速性"。
    界面用 after() 定时刷新，可随时暂停、归零。
  · 存储估算：输入条数与单条字节数，自动换算 KB/MB/GB/TB，
    并按教材锚点（10TB≈66 亿部《红楼梦》、高清电影约 2GB/部）
    给出直观类比——体验大数据"巨量性"。

【标签页3 数据—信息—知识卡片】
  · 三栏分别填写：原始数据 → 场景中的信息 → 归纳出的知识；
  · 点"保存卡片"加入列表，可删除；
  · 卡片会随"实验记录"一起导出（菜单：文件 → 保存实验记录）。

【标签页4 交通拥堵数据统计】
  · 一键生成 300 条各路段车速记录（模拟海量车辆上报数据）；
  · 一键统计各路段平均车速，并按 ≥40 畅通 / 25~40 缓行 / <25 拥堵
    给出判断——体会导航软件"红黄绿"路况背后的大数据原理。

三、菜单栏
  文件：导入 CSV / 导出当前数据集 CSV / 保存实验记录(JSON 或 TXT) / 退出
  操作：重置全部
  帮助：使用帮助

四、常见问题排查
Q1：运行时报 "No module named tkinter"？
    Linux 需安装：sudo apt install python3-tk（Ubuntu/Debian）。
    Windows/macOS 官方安装包自带 Tkinter。
Q2：点"开始"后计数不增长？
    请确认"每秒生成条数"滑块大于 0，且按钮显示为"暂停"（即正在运行）。
Q3：导出的 CSV 用电子表格软件打开出现乱码？
    本工具以 UTF-8（带 BOM）保存，主流电子表格软件均可正确识别；
    若仍乱码，请在打开时手动选择 UTF-8 编码。
Q4：中文界面显示为方块？
    请确认系统安装了中文字体（如微软雅黑、思源黑体等）。

五、说明
  本工具完全离线运行，不联网、不采集任何真实数据；
  所有"骑行记录""车速记录"均由 random 模块虚构生成，仅供教学演示。
