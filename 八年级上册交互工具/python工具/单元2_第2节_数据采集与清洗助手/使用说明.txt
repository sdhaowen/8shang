====================================================
数据采集与清洗助手 · 使用说明
配套课时：清华版《信息科技》八年级上册
第2单元 第2节《数据的采集和整理》
====================================================

一、运行方法
1. 确认已安装 Python 3.8 及以上版本（自带 Tkinter 与 csv/json/statistics，
   无需安装任何第三方库）。
2. 在本文件夹打开终端/命令行，执行：
       python3 数据采集与清洗助手.py
   Windows 下也可以执行：
       python 数据采集与清洗助手.py

二、功能介绍
【数据载入】
  · "载入示例脏数据"：一键载入内置的"校园气象观测"数据表
    （21 行，混有缺失值、重复行、异常值 88℃/-35℃/湿度999、
    "25度/26.5℃"等格式问题，与配套网页工具的数据主题一致，
    本文件夹也附有同样内容的 示例脏数据.csv）。
  · "导入 CSV/JSON…"：文件对话框选择文件，自动检测 UTF-8 / GBK
    编码并在弹窗中提示；JSON 支持"对象列表"或 {header, rows} 结构。
  · 导入的同时程序自动在内存中备份原始数据，所有处理都不会改动
    你的原文件；还可通过"文件→另存原始数据副本"再保存一份原件。

【一键体检】
  右侧生成体检报告：
  · 每列缺失值数量及所在行；
  · 重复行数量（与前面某行完全相同的行）；
  · 可疑异常值：列名含"气温/温度"的列按常识范围 -30~50℃、含
    "湿度"的列按 0~100% 判断；没有常识范围的数值列改用
    "四分位 IQR 法"（低于 Q1-1.5×IQR 或高于 Q3+1.5×IQR 判为可疑，
    小样本时可能误判，需人工复核）；
  · 类型不一致：数值列中混入"度/℃/%"等单位或无法转成数字的值。
  问题行在表格中着色：黄=缺失，紫=重复，红=异常，橙=类型/格式。

【清洗操作】（每一步都写入清洗日志）
  · 删除所选行：先在表格中单击选中（Ctrl 可多选），再点按钮；
  · 删除全部重复行：一键去重，保留第一份；
  · 缺失值填充：选择目标列，用 平均值 / 中位数 / 固定值 填充；
  · 类型转换（文本→数值）：把"25度""26.5℃"统一为纯数字；
  · 列重命名：把不规范列名改规范（数据"统一性"的一部分）；
  · 恢复备份：随时回到导入时的原始数据重新练习。

【导出】
  · 文件→导出清洗后 CSV（UTF-8 带 BOM，电子表格软件可直接打开）；
  · 文件→导出清洗后 JSON（对象列表结构）；
  · 文件→导出清洗日志（txt，可作为实验记录上交）。

三、建议的课堂练习流程
  1. 载入示例脏数据 → 2. 一键体检，数一数四类问题各几处 →
  3. 类型转换("气温(℃)"列) → 4. 删除全部重复行 →
  5. 删除异常行(88 / -35 / 999 所在行) → 6. 缺失填充(平均值) →
  7. 再次体检确认问题清零 → 8. 导出清洗后 CSV 与清洗日志。

四、常见问题排查
Q1：运行时报 "No module named tkinter"？
    Linux 需安装：sudo apt install python3-tk（Ubuntu/Debian）。
Q2：导入时提示"无法识别文件编码"？
    请用记事本/编辑器把文件另存为 UTF-8 或 GBK（ANSI）编码后重试。
Q3：体检没有把某个奇怪的值标为异常？
    IQR 法依赖数据分布，样本太少或异常值扎堆时可能漏判；
    可结合"常识范围"人工判断，选中该行手动删除或修改。
Q4：删除行以后行号变了？
    表格第一列"#"是当前行号，删除后自动重排，属正常现象。

五、说明
  本工具完全离线运行，不联网；示例数据均为虚构教学数据。
  检测与清洗核心函数（to_number / health_report / remove_duplicate_rows /
  fill_missing / convert_column_numeric 等）不依赖界面，可被其他程序导入复用。
